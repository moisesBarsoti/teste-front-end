## ▶️ Como rodar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/teste-front-end.git
```

### 2. Abra a pasta

```bash
cd teste-front-end
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Rode o projeto

```bash
npm run dev
```

### 5. Acesse no navegador

```bash
http://localhost:5173
```
